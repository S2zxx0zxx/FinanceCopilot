# Phase 13 — User Research

## Research Design
Recruit actual beta participants. All sessions require:
- Informed consent for research recording
- Right to withdraw
- Data minimization — no raw financial history in notes

## Core Usability Tasks
1. Connect data source
2. Understand money state (balance, spending)
3. Ask the AI a financial question
4. Inspect evidence/source of an AI answer
5. Correct a transaction
6. Run affordability simulation
7. Review forecast
8. Review goal
9. Export / delete data

## Measurement Per Task
| Dimension | How Measured |
|-----------|-------------|
| Task completion | Binary: completed without prompting |
| Confusion | Observed hesitation, error, backtrack |
| Time on task | Wall clock |
| Confidence | Post-task rating 1-5 |
| Misunderstanding | Verbalised incorrect assumption |
| Next action | What user does after task |

## Interview Questions (§39)
DO NOT ask: "Do you like the app?"
DO ask:
- "What do you think this number means?"
- "Why do you trust/distrust this answer?"
- "What would you do next?"

## Privacy
- Transcripts redacted before storage
- Identifiers minimized
- Research notes access-controlled
- Retention policy: 90 days post-project
