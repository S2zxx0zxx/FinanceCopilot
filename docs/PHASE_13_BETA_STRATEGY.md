# Phase 13 — Beta Strategy

## Objective
Transition FinCopilot from engineered code to observed real-user behavior.

## Beta Philosophy
Beta is NOT "everyone is happy." Beta is:
- Controlled exposure
- Real measurement
- Failure discovery
- Trust validation

A high-quality beta may produce many failures. That is useful evidence.

## Stages
```
INTERNAL → FRIENDS/TESTERS → SMALL INVITED BETA → EXPANDED BETA
```

Gate progression is based on evidence, not calendar dates.

## Current Status
- REAL USERS = 0 (pre-launch, infrastructure ready)
- Phase 13 status: OPEN — awaiting real user onboarding

## Entry Contract for Phase 14
Before declaring Phase 13 VERIFIED_COMPLETE, the product must have:
- Real user evidence (N > 0)
- Controlled, privacy-safe telemetry confirmed active
- No unresolved P0/P1 incidents
- Frozen versioned evidence snapshot with real hash
